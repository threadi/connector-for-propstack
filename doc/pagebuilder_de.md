# PageBuilder

Wir unterstützen eine Vielzahl an PageBuilder, mit denen die Präsentation der Objekte von Propstack sehr einfach vorbereitet werden können.

## Hinweise

Sollte ein PageBuilder hier nicht genannt sein, [gerne bei uns anfragen](https://wordpress.org/support/plugin/connector-for-propstack/). Alternativ kann man jederzeit [Shortcodes](shortcodes_de.md) verwenden, die jedoch weniger flexibel sind.

Die Unterstützung für jeden PageBuilder ist identisch hinsichtlich der Inhalte, die sie ermöglichen. Die Gestaltung dieser hängt vielfach von den Möglichkeiten des jeweiligen PageBuilders ab.

Die meisten PageBuilder werden ausschließlich im kostenpflichtigen Plugin unterstützt. Informationen dazu findest du [hier](https://laolaweb.com/plugins/propstack-wordpress-plugin/propstack-plugin-pro-bestellen/).
